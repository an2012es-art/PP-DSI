# DSI-Playtime: Monster Chase

An original Nintendo DS homebrew prototype. It is inspired by toy-factory horror games, but is not the original Poppy Playtime game.

## Current features
- Move the player with the D-pad.
- A simple monster moves toward the player after each move.
- You lose when the monster catches you.
- Press START after losing to restart.

## Build
Push the files to GitHub, then open **Actions** and run **Build DSI Playtime Chase**. Download the `DSI-Playtime` artifact when the workflow succeeds.

## Important
This is a small 2D prototype, not a complete 3D game. It has no real 3D models, sound, GrabPack mechanics, or original Poppy Playtime assets yet. Test the resulting `.nds` file on an emulator or Nintendo DSi; successful compilation does not guarantee device compatibility.
